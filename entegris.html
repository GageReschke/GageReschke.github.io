Working on the production floor alongside operators and engineers, I track down the causes of inspection data issues, build tools that make inspection faster and more consistent, and give operators what they need to solve routine problems themselves.

Centralized inspection system

My largest project has been replacing the per-product Excel sheets used for inspection with a single, work-order-based inspection system built in Ignition Perspective. Instead of operators finding and filling out a separate spreadsheet for each product, inspections now run through one centralized system tied to the work order.

  • Designed and built the system in Ignition Perspective to replace separate per-product Excel sheets
  • Iterated on the design over several months, using operator feedback and inspection times to guide each revision

Root cause analysis

Day to day, I analyze inspection data to find problems and work back to what caused them, then put corrections in place.

  • Traced inspection data issues to root causes across process equipment and inputs, including ovens, powder mixers, and recipes
  • Implemented corrective actions once causes were confirmed

Greenforming troubleshooting flowchart

I created a reactive troubleshooting flowchart for the membrane greenforming process. It walks operators through diagnosing and resolving minor issues directly on the floor, so routine problems no longer have to wait for an engineer.

3D scanner fixtures

To streamline inspection, I designed multiple SolidWorks fixtures for a 3D scanner, each sized for a different range of parts. I also use SolidWorks for design work and documentation across several other projects.
